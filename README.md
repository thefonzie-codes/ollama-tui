# OLLAMA TUI

Sometimes, I just want to ask AI a question, and i don't want to open a browser or spin up OpenCode, Claude Code, Gemini CLI etc.  And yes, I'm sure this is already available somewhere, but I felt like making my own.

A quick personal project built with Go, using Charmbracelet's Lipgloss and Bubbletea to make a more visually appealing way to work with OLLAMA.
